## 📌 About the Project

**Flowchart To-Do List** is a web application project built with React and TypeScript using Vite. Its flowchart-inspired concept aims to make task planning feel more visual and structured.

The project is also a practical example of building a modern frontend application with a component-based UI and a TypeScript development workflow.

## ✨ Highlights

- 🔀 **Flowchart-inspired task planning** — a visual approach to thinking about tasks and their workflow.
- ⚛️ **React** — build the interface using reusable components.
- 🟦 **TypeScript** — add static typing to the development experience.
- ⚡ **Vite** — fast local development server and production build tooling.
- 🧩 **Frontend-focused architecture** — a starting point for extending the task-planning experience.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Install the following first:

- [Node.js](https://nodejs.org/) — use a currently supported LTS release.
- npm — included with Node.js.
- Git — to clone the repository.

Check that Node.js and npm are available:

```bash
node -v
npm -v
```

### 1. Clone the repository

```bash
git clone https://github.com/Varshith-eati/Flowchart-ToDoList.git
cd Flowchart-ToDoList
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Vite will print a local URL in the terminal, usually:

```text
http://localhost:5173
```

Open the URL shown in your terminal in a browser.

## 📦 Production Build

Check TypeScript and create an optimized production build:

```bash
npm run build
```

Preview the generated production build locally:

```bash
npm run preview
```

Vite outputs the production files to the `dist/` directory.
